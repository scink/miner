# Сапёр (Minesweeper)

Классическая игра Сапёр (Minesweeper) в стиле Windows 95/98 с дополнительной тёмной темой.

## Особенности

- ✅ Классические режимы: Новичок, Любитель, Профессионал, Особый
- ✅ Безопасный первый клик (3×3 зона вокруг первого клика всегда безопасна)
- ✅ Ленивая расстановка мин после первого клика
- ✅ Flood-fill для пустых клеток (итеративный, без рекурсии)
- ✅ Chording: раскрытие соседей по цифре
- ✅ Таймер и счётчик мин
- ✅ Кнопка-лицо (нормальное, удивлённое, мёртвое, очки)
- ✅ Полное меню: Игра, Справка
- ✅ Touch-friendly: режимы касания и долгое нажатие
- ✅ Компактный desktop layout (16px клетки, 26x26 face, 39px LED)
- ✅ Unit-тесты на Node.js

## Запуск

### Локальный HTTP-сервер (рекомендуется)

```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (если установлен)
npx http-server -p 8000

# PHP
php -S localhost:8000
```

Затем откройте: `http://localhost:8000`

### Прямое открытие файла

**ВНИМАНИЕ:** При прямом открытии `index.html` (file://) ES-модули не работают корректно из-за CORS-ограничений. Используйте HTTP-сервер для запуска.

## Управление

### Компьютер

| Кнопка | Действие |
|--------|----------|
| **ЛКМ** | Раскрыть клетку |
| **ПКМ** | Поставить/снять флаг (циклично: закрыта → флаг → вопрос → закрыта) |
| **ЛКМ+ПКМ** | Chording (раскрытие по цифре) |
| **F2** | Новая игра |

### Touch-устройства

- **Краткое касание** — раскрытие (в режиме Reveal)
- **Долгое нажатие** (500мс) — флаг
- **Режим переключения** — в меню или тач-контроле

### Меню

**Игра**
- Новая игра (F2) — начать заново
- Новичок — 9×9, 10 мин
- Любитель — 16×16, 40 мин
- Профессионал — 30×16, 99 мин
- Особый... — кастомные размеры
- Тёмная тема — вкл/выкл тёмную тему

**Справка**
- Управление — как пользоваться игрой
- О программе — информация об игре

## Конфигурация

Последние настройки (сложность, тёмная тема) сохраняются в `localStorage`.

## Технические детали

### Структура проекта

```
miner/
├── index.html          # Главный HTML файл
├── package.json        # Конфигурация (scripts только)
├── README.md           # Этот файл
├── src/
│   ├── Game.js         # Логика игры (без DOM)
│   ├── utils.js        # Утилиты
│   ├── UI.js           # UI и DOM interaction
│   ├── main.js         # Точка входа
│   └── styles.css      # Стили Windows 95
└── test/
    ├── game.test.js    # Unit-тесты
    └── integration.test.js  # Integration тесты
```

### Архитектура

**Game.js** — чистая логика без DOM:
- `Minesweeper` класс
- `CELL_STATE` (CLOSED, FLAGGED, QUESTIONED, REVEALED)
- `STATE` (READY, RUNNING, WON, LOST)
- `DIFFICULTY` (BEGINNER, INTERMEDIATE, EXPERT)

**UI.js** — отображение и ввод:
- `UI` класс
- Обработка событий мыши/touch + F2 (без клавиатурной навигации)
- Меню, диалоги, LED-дисплеи
- Touch-поддержка

**styles.css** — Windows 95 стиль:
- Bevel borders
- 3D эффекты
- LED-дисплеи
- Тёмная тема

### Алгоритмы

**Flood-fill**: Итеративный (стек), не использует рекурсию

**Fisher-Yates**: Частичная перестановка для расстановки мин

**First click safety**: Безопасная зона 3×3 вокруг первого клика
