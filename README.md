# Сапёр (Minesweeper)

Классическая игра Сапёр (Minesweeper) в стиле Windows 95/98 с трёхрежимной темой и поддержкой Telegram WebApp.

## Платформы и развертывание

### 🕹️ Играть в браузере (GitHub Pages)

**Сконфигурированный URL:** [https://scink.github.io/miner/](https://scink.github.io/miner/)

Это публичное статическое приложение GitHub Pages без бэкенда, без пользовательских аккаунтов и без аутентификации. Деплой производится автоматически при пуше в ветку `master` через GitHub Actions.

### 📱 Telegram Mini App

Игра готова к интеграции с Telegram как Mini App. После подключения через BotFather игра будет доступна внутри Telegram.

> **Подключение бота позже**
>
> Чтобы подключить игру к Telegram как Mini App, выберите один из официальных путей:
>
> **Main Mini App:**
> 1. Откройте `/mybots` в BotFather
> 2. Выберите вашего бота → Bot Settings → Configure Mini App
> 3. Нажмите Enable Mini App и укажите URL: `https://scink.github.io/miner/`
>
> **Menu Button:**
> 1. В BotFather используйте `/setmenubutton` или откройте Bot Settings → Menu Button
> 2. Установите текст кнопки и URL: `https://scink.github.io/miner/`
>
> После этого игра будет доступна через кнопку запуска в профиле бота (Main Mini App) или кнопку меню.

## Особенности

- ✅ Классические режимы: Новичок, Любитель, Профессионал, Особый
- ✅ Безопасный первый клик (3×3 зона вокруг первого клика всегда безопасна)
- ✅ Ленивая расстановка мин после первого клика
- ✅ Flood-fill для пустых клеток (итеративный, без рекурсии)
- ✅ Chording: раскрытие соседей по цифре
- ✅ Таймер и счётчик мин
- ✅ Кнопка-лицо (нормальное, удивлённое, мёртвое, очки, пауза, продолжить)
- ✅ Полное меню: Игра, Справка
- ✅ Touch-friendly: панель действий на тач-экранах
- ✅ Компактный desktop layout (16px клетки, 26x26 face, 39px LED)
- ✅ Unit-тесты на Node.js

## Управление

### Компьютер (десктоп)

| Кнопка | Действие |
|--------|----------|
| **ЛКМ** | Раскрыть клетку |
| **ПКМ** | Поставить/убрать флаг (цикл: закрыта → флаг → вопрос → закрыта) |
| **ЛКМ+ПКМ** | Chording (раскрытие соседей по раскрытой цифре) |
| **ЛКМ по раскрытой цифре** | Chording (если соседей больше 0) |
| **F2** | Новая игра |

### Touch-устройства

Панель управления отображается внизу игрового поля только на устройствах с coarse-указателем (тач-экраны).

**Режимы (по умолчанию: Клик):**
- **Вопрос** — закрытая клетка или клетка с флагом становится вопросом; повторное касание клетки с вопросом закрывает её
- **Флаг** — закрытая клетка или клетка с вопросом становится флагом; повторное касание клетки с флагом закрывает её
- **Клик** — раскрыть клетку

**Поведение:**
- Выбранный режим сохраняется во время игры
- При касании раскрытой цифры всегда выполняется chording (независимо от режима)
- На паузе касания не работают

### Меню

**Игра**
- Новая игра (F2) — начать заново
- Новичок — 9×9, 10 мин
- Любитель — 16×16, 40 мин
- Профессионал — 30×16, 99 мин
- Особый... — кастомные размеры
- **Тема: система** — использовать системную тему (Telegram или браузер)
- **Тема: светлая** — всегда светлая тема
- **Тема: тёмная** — всегда тёмная тема

Кнопка темы циклически переключается: `система → светлая → тёмная → система`.

**Справка**
- Управление — как пользоваться игрой
- О программе — информация об игре

### Пауза

Кнопка-лицо в верхней части управления:
- **READY** — неактивна (пауза недоступна до начала игры)
- **RUNNING** — приостанавливает игру, скрывает игровое поле
- **PAUSED** — возобновляет игру
- **WON/LOST** — начинает новую игру

### Панель масштабирования (в заголовке окна)

Три кнопки в верхнем правом углу:
- **−** — переходит к предыдущему фиксированному уровню масштаба;
- **100%** — сбрасывает масштаб на 100%;
- **+** — переходит к следующему фиксированному уровню масштаба.

**Доступные уровни (фиксированная последовательность):** 75% → 100% → 125% → 150% → 175% → 200%

**Примечание:** Кнопка **+** недоступна на уровне 200% (максимальный масштаб).

Масштаб влияет на весь интерфейс (включая панель тач-управления) и участвует в layout-расчётах — при увеличении oversized-доска остаётся доступной для прокрутки. При перезагрузке страницы масштаб сбрасывается на 100% (не сохраняется).

## Тема и Telegram WebApp

### Система тем

Игра поддерживает **три режима темы**, которые циклически переключаются:

- **Тема: система** — использует Telegram color scheme (если доступен и валиден), иначе `prefers-color-scheme` браузера, иначе по умолчанию светлая
- **Тема: светлая** — всегда светлая тема (переопределяет источники)
- **Тема: тёмная** — всегда тёмная тема (переопределяет источники)

**Приоритет разрешения (при режиме `система`):**
1. Telegram color scheme (если `colorScheme` валиден: `light` или `dark`)
2. Браузерный `prefers-color-scheme` (через CSS media query)
3. По умолчанию: `light`

### Telegram WebApp

Игра готова к запуску как Telegram WebApp:

- `Telegram.WebApp.ready()` вызывается **после создания UI** (в порядке: theme.start() → createUi() → ready())
- `Telegram.WebApp.expand()` вызывается **после ready()** и запрашивает максимальную доступную высоту
- При смене темы в Telegram (`themeChanged` event) тема обновляется автоматически в режиме `система`

**Важно:** В браузере без Telegram SDK эти методы вызываются безопасно (без эффекта и ошибок).

### Архитектура

**Game.ts** — чистая логика без DOM:
- `Minesweeper` класс
- `CELL_STATE` (CLOSED, FLAGGED, QUESTIONED, REVEALED)
- `STATE` (READY, RUNNING, WON, LOST, PAUSED)
- `DIFFICULTY` (BEGINNER, INTERMEDIATE, EXPERT)

**UI.ts** — отображение и ввод:
- `UI` класс
- Обработка событий мыши + F2
- Меню, диалоги, LED-дисплеи
- Touch-поддержка (координатная панель действий)
- Масштабирование интерфейса

**theme.ts** — трёхрежимный контроллер темы:
- Поддержка `system`/`light`/`dark` с циклическим переключением
- Интеграция с Telegram color scheme и browser `prefers-color-scheme`
- Сохранение в localStorage

**telegram.ts** — Telegram WebApp bridge:
- Безопасный доступ к SDK с обработкой ошибок
- `ready()` и `expand()` вызовы с fallback
- `onThemeChanged` подписка

**platform.ts** — инициализация:
- Порядок: theme.start() → createUi() → telegram.ready() → telegram.expand()

**styles.css** — Windows 95 стиль:
- Bevel borders
- 3D эффекты
- LED-дисплеи
- Поддержка тёмной темы

### Алгоритмы

**Flood-fill**: Итеративный (стек), не использует рекурсию

**Fisher-Yates**: Частичная перестановка для расстановки мин

**First click safety**: Безопасная зона 3×3 вокруг первого клика
